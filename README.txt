PAZ NAYARIT — DEMO VISUAL V2

Contenido:
- index.html
- assets/

Para probar:
1. Abra index.html en un navegador.

Para subir a cPanel:
1. Suba el contenido de esta carpeta a public_html o a un subdominio/carpeta de prueba.
2. Mantenga la carpeta assets junto a index.html.
3. No requiere PHP ni base de datos para esta demo.

Nota:
Esta versión usa una distribución de color distinta al sitio de Tamaulipas: fondo crema, morado como color institucional, acentos coral, amarillo y turquesa.
